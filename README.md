# TrendFlow AI — P3 Industry-Ready PR1 Module

This module owns:
- PR1 supplier allocation optimization using Google OR-Tools CP-SAT.
- Supplier delay/risk prediction using scikit-learn Logistic Regression.
- Optimization/risk diagnostics and tests.

## Important integration contract
P2 -> P3 request:
```json
{
  "material_id": "MAT001",
  "required_quantity": 30000,
  "required_date": "2026-10-15",
  "plant_id": "PLANT001",
  "priority": "HIGH"
}
```

P3 -> P1 result contains allocation lines with:
- supplier_id
- quantity
- percentage
- unit_price
- total_cost
- risk_score
- expected_delivery_date

## Environment
Use a dedicated virtual environment for P3. Do not rely on the global Python installation.

Windows PowerShell:
```powershell
python -m venv .venv-p3
.\.venv-p3\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-p3.txt
```

## Generate risk training data
```powershell
python scripts/generate_risk_sample.py
```

## Train risk model
```powershell
python -m ml.risk.train
```

## Evaluate risk model
```powershell
python -m ml.risk.evaluate
```

## Generate risk charts
```powershell
python -c "from ml.risk.visualize import generate_diagnostics; generate_diagnostics('data/sample/supplier_performance.csv','models/supplier_risk.joblib')"
```

## Run allocator
```powershell
python -m optimization.supplier_allocation
```

## Generate allocation chart
```powershell
python -c "from datetime import date; from pathlib import Path; from optimization.loader import load_supplier_materials; from optimization.supplier_allocation import SupplierAllocationOptimizer; from optimization.schemas import AllocationRequest; from optimization.visualize import save_allocation_chart; root=Path('.'); s=load_supplier_materials(root/'data/sample/supplier_materials.csv', root/'data/sample/suppliers.csv'); r=SupplierAllocationOptimizer().optimize(AllocationRequest('MAT001',30000,date(2026,10,15),'PLANT001','HIGH'),s,current_date=date(2026,8,23)); save_allocation_chart(r,'reports/allocation.html'); print(r)"
```

## Design principles
- OR-Tools makes the procurement allocation decision.
- ML produces supplier risk scores.
- Gemini should explain existing results later; it must not override the optimizer.
- P3 does not implement invoice OCR, payments, 3-way matching, or autonomous P2P.
